# Paradigmas de Programação

## Paradigma → O que é paradigma?

São modelos ou padrões de programação. São padrões que servem para guiar o desenvolvimento do código.

## 4 paradigmas vistos durante o semestre

**Imperativo** → BASIC, Lua, Rust, Go, C++

**Orientado a Objetos** → C++, C#, Python, Ruby, JavaScript, Java

**Funcional** → Haskell, LISP

**Lógico** → Prolog

## Estrutura Usada

A cada semana será um relatório. Logo, a estrutura a ser seguida será:

```text
Relatorio 01/
├── Exercicio 01.bas
├── Exercicio 02.bas
└── ...
```

Dentro dessa pasta deverão estar os exercícios, com a extensão correta.

* `.bas` = BASIC
* `.py` = Python

## Observação quanto ao Uso de IA

Se houver o uso de IA em algum relatório, essa ação deve ser reportada usando um arquivo `IA_REPORT.md`, que deve conter o histórico completo de uma sessão e seus respectivos prompts e respostas.

Além disso, deverá conter um relatório de aprendizado no qual deve ser explícito:

* Como a resposta ajudou na solução do problema;
* De que forma ela solucionou a sua dúvida;
* O que você aprendeu com aquele retorno para aplicar em problemas futuros.
